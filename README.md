# Ahmed Ben Hamouda — Developer Portfolio

A dark, animated, bilingual (DE/EN) static portfolio focused on a single software project: **MensaConnect**.

## Run locally

Double-click `index.html` to open the site in Safari or Chrome. The site requires no build process, frameworks, account, API key or backend.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `ahmed-ben-hamouda.github.io`.
2. Upload **the contents of this folder** (`index.html`, `case-study.html`, `assets/`, etc.) into the repository root. Do **not** upload the ZIP as one file.
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, then `main` and `/(root)`.
4. Your expected public URL will be `https://ahmed-ben-hamouda.github.io` when deployment completes.
5. Add this public URL to LinkedIn's Contact Info / Featured area.

## Update later

As new projects are actually developed, add new project cards to the `#work` section. Keep the work descriptions grounded in features you've implemented, and don't claim prototypes are publicly released.

## Motion and accessibility

The site honors `prefers-reduced-motion`, works with keyboard navigation, and uses no remote scripts or analytics. All images and CSS/JS assets are local.
